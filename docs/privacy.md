# 隐私与数据说明

本文说明当前 MVP 的实际行为。Worklog 默认用于本机个人工作记录整理，没有云同步、团队账户、后台持续监听或遥测功能。

## 本地数据

导入器将所选来源文件中的消息正文、时间、元数据和来源路径写入 SQLite。默认数据库为 `.worklog/worklog.db`。工作事件和报告也保存在该数据库中；Markdown、HTML 和 Excel 输出默认保存在 `.worklog/exports/`。数据库与导出文件没有由应用额外加密，依赖操作系统的文件权限和磁盘保护。

代码模式的扫描、导入、规则分析和报告生成不调用外部模型。安装 Python / npm 依赖需要网络，与生成报告的代码模式无关。

导出文件会包含工作摘要和对话证据，可能包含原文、项目名、路径、链接或其他私人信息。分享文件前请检查具体内容；不要将自己的数据库、聊天记录、接口配置或生成报告作为公开仓库中的示例提交。

## AI 请求的内容

只有主动调用 AI 生成接口或点击「AI 模式」才会调用模型服务。模型供应商可能是 OpenAI、Anthropic，也可能是用户通过 CCSwitch 或自定义 Base URL 配置的中转服务。发送给中转的内容仍可能被转发给其上游，具体处理方式取决于该服务。

当前请求包括日期范围、报告标题、按类型和项目整理的工作事件，以及关联的消息片段。事件摘要来自消息文本，最多 500 个字符；默认的证据片段取每条关联消息的前 1,200 个字符。因此，不启用完整原文也不代表请求不含原文或敏感内容。

API 支持 `message_ids` 和 `include_raw` 参数。未指定非空的消息 ID 列表时，会选择该报告的全部证据消息；空数组不会清空选择。`message_ids` 只控制额外的消息片段，不会排除报告中其他事件的摘要。`include_raw=true` 会发送所选消息的完整正文与元数据。

`POST /api/ai/preview` 可以查看待构造的上下文。但当前 Web 没有预览确认界面，也没有逐条选择消息的交互；点击「AI 模式」会直接请求生成。预览接口支持的 `redaction_terms` 当前尚未传递到生成流程，不能把预览中的脱敏结果视为实际请求已脱敏。涉及敏感记录时，请使用代码模式，或在导入前制作并使用脱敏副本。

模型输出会经过基础结构校验。模型请求或受支持的输出校验失败时，生成流程会保留代码模式草稿及错误信息；当前错误处理和校验仍在完善。

## 密钥和接口配置

API Key 支持以下环境变量：

- `WORKLOG_OPENAI_API_KEY`
- `WORKLOG_ANTHROPIC_API_KEY`
- `WORKLOG_CCSWITCH_API_KEY`

环境变量优先于进程内保存的密钥和系统密钥链。设置页保存的密钥会尝试写入操作系统密钥链，服务名为 `worklog`。若系统密钥链不可用，当前版本会静默退回进程内存，重启服务后需重新输入；界面的「已保存」暂不区分持久保存是否成功。

应用不会将 API Key 作为字段存入 SQLite、报告或 `.worklog/provider-settings.json`，也没有主动记录密钥的日志。请不要把密钥放进 Base URL、模型名或聊天正文；这些字段可能被保存或导出。系统密钥链中的密钥需要在系统提供的密钥管理工具中管理。

服务商、兼容协议、Base URL 和模型名以明文保存到 `.worklog/provider-settings.json`。它被 Git 忽略。请只配置你信任且确实可用的服务地址。CCSwitch 配置留空 Base URL 时，当前实现会使用所选协议的官方地址，不会自动发现本地中转。

## 本地服务的范围

本地 API 目前没有用户认证，并且拥有当前进程的文件访问权限，导入接口可以读取指定路径。请按 README 以 `127.0.0.1` 启动，不要把它当作可直接公开部署的多用户服务。

浏览器中的报告修改目前只保存在页面状态中，不会更新数据库或导出文件。API 下载接口会重新生成代码模式报告，不能用于下载尚未保存的编辑内容或此前的 AI 草稿。
